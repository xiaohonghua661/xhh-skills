# xx — 学习闭环

目标：对抗遗忘曲线（默认 24 小时忘掉约 70%）。每次 `/xx` 跑一轮结构化闭环，把"看懂"变成"记住、会用"。

两把硬武器（学习科学定论）：**主动回忆（考自己）** + **间隔重复（在快忘时再考）**。其余三招是放大器。

## 触发

用户打 `/xx`，或说"考我 / 复习 / 学习 / 开始学"时启动。**本技能独立运行，不依赖 dd 或任何外部工具。**

## 错题本（间隔重复的唯一存储）

- **位置**：当前工程 `docs/` 下的 `错题本.md`（本仓库在 `docs/学习资料/错题本.md`）。没有就新建。
- **本质**：一个纯 markdown 表，不走 dd、不依赖外部工具，可随工程一起版本控制。
- **列**：`# | 考点 | 正解（要点） | 我当时的错/易错点 | 阶段 | 下次复习(YYYY-MM-DD)`
- **间隔阶梯**：答对升一级 **1 → 3 → 7 → 16 天**；答错退回阶段 1，下次复习 = 今天 + 1 天，不得写成今天。
  下次复习 = 今天 + 阶梯天数（用当前真实日期算，不要硬编码）。

## 自适应题型（复用阶段，不新增列）

把“阶段”同时作为掌握度和题目难度；阶段缺失或无效时按阶段 1。阶段 4 为上限，答对后保持阶段 4，下次复习 = 今天 + 16 天。

| 当前阶段 | 默认题型 | 检查目标 |
|---|---|---|
| 阶段 1 | 填空；二元结论用判断；易混概念用二选一 | 先建立正确边界，降低表达负担 |
| 阶段 2 | 三选一或短填空 | 排除真实干扰项，检查辨析 |
| 阶段 3 | 简答或对比题 | 独立组织因果关系 |
| 阶段 4 | 费曼复述或项目情境题 | 迁移到真实问题 |

按人类作答习惯出题：

- 一次只出一题。填空只挖 1～2 个核心词，接受语义等价答案，不要求逐字一致。
- 选择题给 2～4 个互斥选项；干扰项取自错题本中的真实误区，不放明显凑数项。
- 判断题禁用双重否定；用户判断后再用一句理由确认是否真正理解。
- 阶段 1 禁止直接要求完整费曼复述；阶段 3 之前不连续使用开放问答。
- 题型与知识结构冲突时优先改用同阶段其他题型，允许降级，不得越级提高难度。

## 每轮 /xx 的闭环（5 步，按顺序）

### 1. 开场闭卷考（主动回忆 + 间隔重复）
- 读错题本，挑「下次复习 ≤ 今天」的**到期卡**。
- **闭卷**逐张问：按当前阶段选择题型，围绕考点出题但不给正解。答完再对答案。
- 判为“正确 / 部分正确 / 错误”：只有核心边界完整才算正确；语义正确即可，不按措辞逐字评分。
- 正确 → 阶段 +1（最高阶段 4），下次复习 = 今天 + 新阶段间隔；部分正确或错误 → 阶段 = 1、下次复习 = 今天 + 1 天（不得写成今天），并把本次真实误区写入“我当时的错/易错点”。
- 部分正确或错误后，先只讲一个关键漏洞，再立即出一道更简单的**校正题**：优先填空，其次判断或二选一。校正题答对只表示当场听懂，不抵消首次错误、不升级阶段。
- 校正题再次答错时，换一种更简单题型并只再校正一次；仍错则给出正解和一个具体例子，保持阶段 1 / 今天 + 1 天复习，结束该考点当天追问，避免无限循环。
- 校正题尚未完成时不切到下一张卡；校正完成或达到两次上限后再继续本轮。
- 没有到期卡就说明"今天无到期复习"，直接进第 2 步。

### 2. 定今天主线（交错 + 项目锚定）
- 接着上次进度，或问用户今天学什么。
- 每个概念都**锚到真实项目任务**（本仓库 = 蓝牙音箱 / 杰理 AC79；换工程锚到它自己的目标）。
- 有意**交错**：别一条道学到黑，穿插上次学过的点做混合练习。

### 3. 讲 + 复述（费曼）
- 我讲一段，**小颗粒，一次一个概念**，别信息倾泻。
- 让用户**用人话讲回来**（讲给小白听）。
- 我挑漏洞、纠错，直到能讲清楚为止。

### 4. 最小实验（上手，可选）
- 给一个能真跑、能**亲眼看现象**的最小 demo（如故意制造任务饥饿、双任务 blink 看抢占）。
- 编译/硬件就绪时优先动手；不便做就用代码走查 + 预测输出代替。

### 5. 收尾入库（喂养间隔重复）
- 今天尚不存在的**新考点**才追加进错题本（阶段 1、下次复习 = 今天 + 1 天）；已有卡答错/卡壳时只更新原行，禁止创建重复卡。
- 一句话小结：今天学到什么、下次从哪接。

## 硬规则

- **闭卷优先**：考的时候先不给答案，主动回忆才有效。
- 一次一个小颗粒，禁止信息倾泻。
- 难度随阶段上升；答错先搭脚手架，不用连续开放问答制造挫败感。
- **错题本是唯一的进度真相**：每轮都要读它、更新它。
- 全中文，UTF-8 无 BOM。
